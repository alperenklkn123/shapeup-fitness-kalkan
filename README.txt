SHAPE KIDS WEBSITE PACKAGE / Shape Training Club Kalkan

Contents:
  shape-kids/index.html — mobile-friendly standalone page in EN/TR/DE/RU
  install_shape_kids.py — adds 'SHAPE KIDS' to the homepage navigation and Quick Access area

INSTALLATION
1. Download or open your current shapeup-fitness-kalkan GitHub website repository locally.
2. Copy the `shape-kids` folder into its root (alongside your existing `index.html`).
3. Copy `install_shape_kids.py` into the repository root.
4. Run: python3 install_shape_kids.py
5. Review the changes. Commit and push to GitHub Pages once ready to publish.
6. Page URL after publication: https://shapetrainingclub.net/shape-kids/

IMPORTANT
- No payment prices or fixed class times are published until confirmed.
- Age groups (6–9, 10–13) are provisional and can be updated.
- Registration currently prepares a WhatsApp message to the club's existing number.
  It does not save data in a database or automatically submit it.
- Before launching paid sessions for children, verify permission, instructor suitability,
  parent authorization, insurance and safeguarding procedures.
- If the homepage structure has changed, the installer will stop without making changes.
